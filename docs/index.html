Всё, что нужно, — и ничего лишнего

Обычный VPN — всё или ничего: банки видят чужой адрес или не открывается YouTube. Waypoint решает это для каждого соединения отдельно.

🖥

Все приложения

Системный туннель перехватывает TCP и UDP любого приложения: Telegram, Discord, игры — без настройки каждого.

🏁

Незнакомые сайты

Первый пакет идёт напрямую, а если путь молчит — тот же пакет повторяется через VPN. Заблокированное открывается за секунду и запоминается.

🎛

Сценарии

Один переключатель — набор правил: «TikTok — свежая лента», «Банки только напрямую», видео, соцсети, голос и игры, AI, публичный Wi-Fi.

🎯

Каждое соединение

Для приложения, сайта или пары «приложение → сайт» выберите путь: авто, VPN, напрямую, блок или конкретный сервер.

🌍

Подписки и серверы

Ссылка подписки провайдера — и серверы обновляются сами. vless, trojan, hysteria2, ss, vmess; сложные Reality-серверы берёт на себя Xray.

🩺

Диагностика

Проверяет цепочку от сети до страны выхода, маршруты по популярным сайтам, TikTok, Telegram и Discord — понятным языком.

Как это устроено

Перед вашим VPN-клиентом встаёт свой туннель. Он решает, куда идёт каждое соединение, и умеет обходить полнотуннельный VPN.

Выглядит как часть macOS

Liquid Glass на macOS 26, тёмная тема, боковая панель без лишнего шума. Каждый сервис, сценарий и приложение настраиваются в пару кликов.

Безопасно по умолчанию

Сетевой инструмент не должен ломать сеть и не должен требовать слепого доверия.

Ломается — сеть остаётся

VPN отключился, Waypoint закрыт или сбой самого туннеля — туннель гасится, и трафик идёт обычным путём. Потом сам повторяет попытку через 1, 5 и 30 минут.

Ваши данные — ваши

Ссылка подписки и серверы хранятся только у вас и нигде не показываются. Waypoint не читает настройки и подписки другого VPN-приложения.

Только легальные разрешения

Системный компонент ставится один раз через стандартное окно macOS с паролем. Он выключен по умолчанию и не обходит защиту системы.

Открытый код

Лицензия MIT. Внутри работают sing-box и Xray-core как отдельные процессы; их версии закреплены, а контрольные суммы проверяются.

Установка

Нужны Mac с Apple Silicon и macOS 14 или новее. Liquid Glass — на macOS 26.

  1. Скачайте Waypoint-…-macos-arm64.zip из Releases и распакуйте.
  2. Перенесите Waypoint.app в ~/Applications и снимите карантин — приложение подписано только ad-hoc:
xattr -dr com.apple.quarantine ~/Applications/Waypoint.app
open ~/Applications/Waypoint.app
  1. Для режима «Все приложения» один раз нажмите «Установить» — macOS спросит пароль.

Или соберите сами:

git clone https://github.com/Zent0rn0/Waypoint.git && cd Waypoint
scripts/fetch-vendor.sh   # sing-box и Xray с проверкой SHA-256
scripts/bundle.sh         # → build/Waypoint.app

Честно об ограничениях

  • Серверами самого VPN-клиента Waypoint не управляет и не читает их: клиент для него — один из вариантов выбора.
  • Если сервис блокирует на своей стороне (отказ приходит уже в HTTP), автоматически это не определить — такие сервисы заданы каталогом и сценариями.
  • Голос и игры без имени сайта по умолчанию идут напрямую; сценарий «Голос, звонки и игры» отправляет их через VPN.
  • Клиенты с балансировкой выходят из разных стран: для TikTok закрепите страну правилом «через сервер».
  • Не проверено: смена Wi-Fi, сон и пробуждение, очень долгая работа.
