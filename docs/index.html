Waypoint

Программа для Mac, которая сама решает, какие сайты и приложения открывать через VPN, а какие напрямую.

Скачать Исходный код

Для Mac с Apple Silicon, macOS 14 или новее. Бесплатно, лицензия MIT.

Для чего это нужно

Обычный VPN либо включён для всего, либо выключен. Если он включён, банки и Госуслуги видят чужой адрес и могут не работать. Если выключен, не открываются заблокированные сайты.

Waypoint решает это отдельно для каждого соединения: то, что иначе не откроется, идёт через VPN, всё остальное идёт напрямую, быстро и без расхода VPN-трафика. Вам нужен VPN-клиент, который уже стоит на компьютере, например Happ. Waypoint работает поверх него.

Что он умеет

  • Работает со всеми программами, а не только с браузером: Telegram, Discord, игры.
  • Если сайт незнакомый, сначала пробует открыть его напрямую. Если не получилось, повторяет запрос через VPN и запоминает результат.
  • Есть готовые наборы правил. Один переключатель, и, например, весь TikTok идёт через VPN, а банки только напрямую.
  • Для любой программы или сайта можно задать путь вручную: через VPN, напрямую, заблокировать или через выбранный сервер. Можно даже для пары «эта программа на этом сайте».
  • Достаточно вставить ссылку подписки от VPN-провайдера. Список серверов скачается и будет обновляться сам, а Waypoint проверит, какие из них работают, и выберет самые быстрые.
  • Вкладка «Диагностика» проверяет, что всё работает, и понятно объясняет, если что-то не так.

Что будет, если что-то сломается

Если VPN отключился, Waypoint закрыт или произошёл сбой, интернет продолжает работать как обычно, просто без Waypoint. Потом он сам пробует запуститься снова.

Ссылка подписки и список серверов хранятся только на вашем Mac и нигде не показываются. Waypoint не читает данные другого VPN-приложения. Системная часть устанавливается один раз, через обычное окно macOS с запросом пароля.

Установка

  1. Скачайте архив Waypoint-…-macos-arm64.zip со страницы релизов, распакуйте и перенесите Waypoint.app в папку ~/Applications.
  2. Программа не подписана Apple, поэтому macOS её блокирует. Один раз выполните в Терминале:
xattr -dr com.apple.quarantine ~/Applications/Waypoint.app
  1. Откройте Waypoint. Чтобы он работал со всеми программами, нажмите «Установить» на главном экране и введите пароль от Mac. Это делается один раз.

Если хотите собрать программу сами:

git clone https://github.com/Zent0rn0/Waypoint.git
cd Waypoint
scripts/fetch-vendor.sh
scripts/bundle.sh

Ограничения

  • Waypoint не управляет серверами самого VPN-клиента и не читает их. Для него клиент — один из вариантов, через которые можно пойти.
  • Если сайт сам не пускает вас (а не провайдер), автоматически это не определить. Такие сервисы заданы заранее в списках и наборах правил.
  • Голос в Discord и игры по умолчанию идут напрямую. Чтобы отправить их через VPN, включите набор правил «Голос, звонки и игры».
  • Не проверялось: смена Wi-Fi, сон и пробуждение компьютера, очень долгая работа.
