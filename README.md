# Waypoint

Умная маршрутизация для macOS: **каждое соединение любого приложения идёт напрямую или через ваш VPN — и Waypoint сам выясняет, как именно.**
Работает поверх любого VPN-клиента с локальным SOCKS5 (проверено с Happ), ничего в нём не меняет и не читает его подписку.

## Что умеет

| | |
|---|---|
| **Все приложения** | Режим туннеля (TUN на `sing-box`) перехватывает TCP и UDP любого приложения: Telegram, Discord, игры — без настройки каждого |
| **Незнакомые сайты** | «Гонка»: первый пакет уходит напрямую, а если прямой путь молчит — тот же пакет повторяется через VPN. Заблокированное открывается за ≈1 с и запоминается (после повторной проверки) |
| **Сценарии** | Один переключатель — набор правил: *TikTok — свежая лента*, *Банки только напрямую*, *Видео*, *Соцсети*, *Голос и игры*, *AI*, *Публичный Wi‑Fi (всё через VPN)*, *Экономия трафика*, *Я за границей* |
| **Правила по приложениям** | «Discord — всегда через VPN» покрывает и все его вспомогательные процессы (Electron) |
| **Каждое соединение** | Для приложения, сайта или пары «приложение → сайт» можно выбрать любой путь: авто, лучший VPN, напрямую, блок, только VPN-клиент или **конкретный сервер** («Telegram — через Германию», «Discord целиком через VPN, а discord.com — напрямую»). В «Приложениях» — кнопка ⋯ и список адресов, куда приложение ходит прямо сейчас; в «Активности» — правый клик по соединению |
| **Подписки провайдера** | Ссылка подписки `https://…` (или импорт-ссылка Happ, v2rayN, sing-box, Clash, Hiddify): список серверов скачивается и обновляется сам, видны остаток трафика и срок. Форматы: список ссылок (обычный и base64), JSON sing-box, JSON Xray |
| **Умный выбор сервера** | Серверы подписок и ваши ссылки (`vless://`, `trojan://`, `ss://`, `hysteria2://`, `vmess://`, `https://` — HTTPS-прокси) соревнуются с VPN-клиентом отдельно за видео, AI, голос и остальное |
| **Живые соединения** | Каждое соединение системы: приложение, адрес, путь, через что, сколько байт |
| **Диагностика** | Проверяет каждое звено: сеть → VPN → страна выхода → туннель → маршруты по сайтам → TikTok, Telegram, Discord |
| **Автозапуск** | Waypoint при входе; VPN-клиент вместе с Waypoint; демон туннеля — при загрузке системы |
| **Списки сообщества** | Опционально: публичные списки заблокированного в РФ, Telegram, TikTok, банков и «доступного только изнутри РФ» |

## Установка

Нужны Apple Silicon Mac, macOS 14+ (Liquid Glass — на macOS 26+, на более старых системах интерфейс обычный) и Swift 6.

```bash
scripts/fetch-vendor.sh                   # один раз: sing-box и Xray из официальных релизов, суммы SHA-256 сверяются
scripts/bundle.sh                         # собирает build/Waypoint.app (с установщиком внутри) и build/waypoint
cp -R build/Waypoint.app ~/Applications/ && open ~/Applications/Waypoint.app
```

Готовая сборка (`Waypoint-<версия>-macos-arm64.zip`) лежит в [Releases](https://github.com/Zent0rn0/Waypoint/releases). Приложение подписано только ad-hoc, поэтому после скачивания macOS его заблокирует: распакуйте, перенесите в `~/Applications` и снимите карантин:

```bash
xattr -dr com.apple.quarantine ~/Applications/Waypoint.app
```

Установка системного компонента спрашивает пароль администратора — так и должно быть.

При первом запуске откроется приветствие: каждый пункт — ваше отдельное согласие.
Демон туннеля ставится один раз: кнопка «Установить демон» в приложении (стандартное окно macOS с паролем/Touch ID)
или `scripts/install-daemon.sh` в Терминале. Он стартует с **выключенным** туннелем.

Удаление: «Настройки → Удалить демон» или `scripts/uninstall-daemon.sh` — TUN и его маршруты исчезают вместе с процессом.

## Как это устроено

```
любое приложение ─▶ TUN Waypoint (sing-box) ─┬─▶ direct-phys    сокет привязан к Wi‑Fi/Ethernet: обходит VPN-клиент
                                             ├─▶ pool-*         лучший из: туннель VPN-клиента + ваши серверы, по классам трафика
                                             └─▶ waypoint-race  незнакомый веб-трафик → Swift-«гонка», которая учится
```

Порядок правил (сверху вниз, первое совпавшее): локальная сеть → **пара «приложение → сайт»** → блок → **приложение** → ваши правила → **сервисы и сценарии** →
«только изнутри РФ» → **выученное** → стартовые списки и списки сообщества → QUIC (отклонить) → гонка → по умолчанию напрямую.
Явный выбор всегда сильнее выученного: даже ошибочно выученный домен не утащит банк через чужой адрес.

Обучение осторожное: одна неудача ничего не значит. Домен выучивается после двух отказов прямого пути **и** повторной проверки; раз в 6 часов
выученное перепроверяется в фоне и забывается, если прямой путь снова работает (блокировку сняли, вы в другой сети).

Приёмы macOS: сокет, привязанный к физическому интерфейсу (`IP_BOUND_IF`), — «прямое» соединение обходит полнотуннельный VPN без root;
`sing-box` запускается через `/bin/sh`, чтобы получить доступ к таблицам ядра (см. ограничения); PAC-файл + системный прокси для режима без демона;
`scutil --nc` — запуск и остановка системного VPN.

## Подписки

Вставьте на экране «Серверы» ссылку подписки от провайдера. Подходят `https://…` и ссылки импорта других клиентов:
`happ://add/https://…`, `v2rayn://install-sub?url=…`, `sing-box://import-remote-profile?url=…`, `clash://install-config?url=…`, `hiddify://import/…`.

- Скачивается честно: собственный User-Agent `Waypoint/0.2`, без заголовков идентификатора устройства; Waypoint не выдаёт себя за другой клиент. Сначала через VPN-клиент, при неудаче — напрямую.
- Каждый сервер — из списка ссылок или из JSON sing-box / Xray — проходит тот же строгий разбор, что и вставленная вручную ссылка. Серверы, которые sing-box не умеет (VLESS-Reality у части провайдеров, транспорт xhttp), берёт на себя Xray: он работает как отдельный процесс, а sing-box ходит к нему по loopback. Что не открылось ни одним движком — пропускается с объяснением.
- **Проверка серверов.** Кнопка «Проверить серверы» (и `waypoint servers audit`) пробует каждый сервер сначала в sing-box, затем в Xray и выбирает движок, который работает; заодно показывает задержку и страну, которую видят сайты. Нерабочие и «российские» (в регионе «Россия») выключаются сами.
- Обновляется раз в 12 часов или как просит провайдер (`profile-update-interval`); показывает трафик и срок из `subscription-userinfo`, название из `profile-title`.
- Ваши включения и выключения серверов при обновлении сохраняются. В регионе «Россия» серверы в России добавляются выключенными (через них заблокированное не откроется, а TikTok увидит российский регион); автоматически включается не больше 40 серверов — каждый включённый сервер регулярно проверяется.
- Зашифрованные ссылки `happ://crypt…` не поддерживаются: их может открыть только Happ. Нужна обычная ссылка подписки.
- Проверить подписку, ничего не сохраняя: `waypoint sub test "<ссылка>"`.

## Безопасность

- Демон от root **выключен по умолчанию** и включается флагом в вашей папке данных. Он читает пользовательские файлы (настройки, правила, серверы, списки), а пишет только в свой `/var/db/waypoint`.
- В конфиг `sing-box` попадают только проверенные значения (интерфейсы `en|utun…`, домены `[a-z0-9._-]`, пути приложений без `..`, кавычек и `\`). Каждый конфиг перед запуском проверяется `sing-box check`; сервер или список, ломающий его, отключается, а туннель всё равно стартует.
- **Fail-open.** VPN не подключён, Waypoint не запущен, `sing-box` падает, самотест цепочки не проходит при рабочей сети — демон гасит туннель, и трафик идёт обычным путём. Затем автоповторы через 1, 5 и 30 минут; сбой самой сети (сон, роуминг) туннель не выключает.
- Локальный API `sing-box` слушает только `127.0.0.1`, секрет лежит в `/var/db/waypoint/api.json` (доступ только у владельца данных).
- Гоночный прокси слушает только `127.0.0.1` (при разработке найдена и исправлена привязка к `*:порт`).
- Waypoint **не читает и не расшифровывает** подписку/серверы другого приложения. Свои серверы — только те ссылки, что вы вставили сами.
- Списки сообщества скачивает приложение (не демон) и только после вашего включения; формат проверяется, испорченный список отбрасывается.
- Приложение в `~/Applications` доступно на запись вашему пользователю; установщик демона берёт его файлы (контрольная сумма проверяется только у `sing-box`). Для более строгой целостности держите приложение в `/Applications`.

## Что проверено

94 автотеста (правила, правила соединений, подписки и их форматы, политика, ссылки серверов, конфиг `sing-box` через настоящий `sing-box check` для 16 комбинаций, гонка на loopback, весь прокси, API соединений, загрузчик списков, резервные копии) и живые проверки на реальной сети: гонка и обучение, TikTok через туннель (регион не РФ), правило по приложению под root-демоном, отказоустойчивость пула (мёртвый сервер не выбирается), аварийное отключение и автовосстановление, остановка и запуск VPN-клиента (туннель уходит в ожидание и возвращается сам), интерфейс в настоящем окне.

## Сторонние компоненты

Waypoint запускает два отдельных процесса и не включает их код в себя: **sing-box** (GPL-3.0-or-later с дополнительным условием об использовании имени, SagerNet) и **Xray-core** (MPL-2.0, XTLS). Их лицензии скачиваются вместе с бинарниками в `vendor/` и кладутся внутрь приложения. Списки блокировок сообщества (runetfreedom) скачиваются самим приложением только после вашего включения.

## Честные ограничения

- **Серверы самого VPN-клиента** Waypoint перечислить не может (и не пытается): клиент сам решает, каким сервером ходить. Умный выбор работает среди *ваших* серверов и клиента как одного кандидата. Клиенты с балансировкой выходят из разных стран на разных соединениях — для TikTok закрепите один сервер в клиенте.
- **Выбор среди своих серверов:** пулы по классам трафика (общий, видео, AI, звонки) выбирает sing-box по задержке каждые 3 минуты, «мёртвый» не выбирается. Проверено на живой подписке (28 серверов: 25 работают, 24 включены; одни через sing-box — hysteria2, другие через Xray — VLESS-Reality). Выбирается лучший по задержке, а не по стране: для TikTok закрепите страну правилом «через сервер».
- **Блокировка на стороне сервиса** (claude.ai, chatgpt.com): TLS проходит, отказ приходит в HTTP, антибот выглядит так же — автоматически не определить, поэтому такие сервисы заданы каталогом и сценариями. TikTok «работает» и напрямую, но с регионом РФ (старая лента) — это не блокировка, для него нужен явный сценарий.
- **UDP без имени** (голос Discord, игры) по умолчанию идёт напрямую; сценарий «Голос, звонки и игры» отправляет весь неопознанный UDP через VPN (заодно и звонки, и российские сервисы по UDP).
- Системный резолвер macOS ходит через интерфейсно-привязанный сокет и не попадает в TUN, поэтому имя сайта берётся из TLS SNI / HTTP Host (для правил и обучения этого достаточно).
- **Не проверено:** смена Wi‑Fi, сон и пробуждение, долгая работа. Кнопка обновления системного компонента в приложении вызывает стандартный запрос macOS; выполнение самого установщика проверено в Терминале и через приложение.
- `sing-box`, порождённый напрямую нашим (самоподписанным) процессом, теряет доступ к таблицам ядра и не находит процесс/шлюз; запуск через `/bin/sh` это лечит. Причина не выяснена до конца.

## CLI

```
waypoint run [--port N]        прокси + журнал решений (то же, что в приложении)
waypoint doctor [--full]       проверка; --full — вся цепочка, маршруты по сайтам, TikTok, Telegram, Discord
waypoint check <хост>...       открыть хост обоими путями и объяснить, какой нужен
waypoint why <хост>            какое правило сработает
waypoint learned [list|clear|forget <домен>]
waypoint rules [list|add "vpn app:/Applications/Discord.app"|remove "..."]
waypoint tunnel on|off|status|conns   режим туннеля; conns — живые соединения
waypoint conn [list|add [--app <путь>] [--site <сайт>] <direct|vpn|client|block|server:<имя>>|remove <app|*> <site|*>]
waypoint vpn status|start|stop        VPN-клиент (то же, что делает приложение при запуске)
waypoint sub test "<ссылка>"          скачать подписку и показать серверы (ничего не сохраняет, ссылку не печатает)
waypoint happ-sync [--activate] [--open]   профиль маршрутизации для Happ из выученного
waypoint proxy on|off|status   системный PAC (для режима без демона)
```

Правила (`~/Library/Application Support/Waypoint/rules.txt`): `vpn youtube.com` · `direct sberbank.ru` · `block ads.example.com` · `vpn full:api.site.com` · `vpn keyword:tiktok` · `direct cidr:10.0.0.0/8` · `vpn app:/Applications/Discord.app`.
`WAYPOINT_HOME` переносит все данные (удобно для тестов).

`swift test --scratch-path /tmp/wp-build` — тесты (в `~/Documents` подпись тестового бандла падает из-за атрибутов iCloud, поэтому сборка во временный каталог).
`Waypoint --render-preview <папка>` рисует экраны в PNG без разрешений; `Waypoint --snapshot <папка>` снимает все страницы настоящего окна (работает и при заблокированном экране); `Waypoint --show-window [экран]` открывает окно при запуске.
